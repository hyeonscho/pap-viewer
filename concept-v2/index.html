실험 데이터를 불러오는 중입니다.

큰 한국어 문장은 영어 정의의 핵심을 풀이한 설명입니다. 작은 영어는 모델 원문이며, 실제 의미와 이미지의 일치 여부를 새로 판정한 것은 아닙니다.

그림은 모델에 넣은 실제 28×28 PNG입니다. 보기 위해 확대했고 픽셀 값은 바꾸지 않았습니다. 8×8 밖은 밝기 128로 가려져 있습니다. 모델의 영어 원문을 그대로 표시하며, 설명이 이미지와 일치한다고 보증하지 않습니다.

확인한 것과 아직 모르는 것

정의 수가 줄고 기존 concept을 참조하는 표현이 생성됐습니다. 같은 시각적 차이를 빠짐없이 표현했는지, 실제 이미지와 설명이 맞는지는 아직 검증하지 않았습니다. 아래 수치는 모델의 제안과 인용 기록입니다.

02 / 결과

같은 관찰, 달라진 출력

Dataset마다 원본 210장과 원본당 5개 관찰을 사용했습니다. 같은 1,050개 관찰을 한 번에 주거나, 210개씩 5회 주면서 이전 concept을 전달했습니다. 각 행은 독립 catalog입니다.

Dataset · 입력v1 정의v2 정의v2 표현part 2개 이상

표현 수에는 concept 하나만 쓰는 경우도 포함됩니다. 마지막 열은 직접 참조한 part가 2개 이상인 표현 수입니다. 같은 concept을 서로 다른 역할로 두 번 참조할 수도 있습니다.

MNIST · 순차

첫 batch에서 정의한 8개를 끝까지 사용했습니다. B2–B5에서는 새 정의를 추가하지 않았고, 71개 표현이 이전 concept을 직접 참조했습니다.

Fashion-MNIST · 순차

B1에서 8개, B2에서 3개를 정의했습니다. B3–B5에서는 새 정의를 추가하지 않았고, 62개 표현이 이전 concept을 직접 참조했습니다.

03 / 무엇을 바꿨나

정의와 사용 예를 따로 저장합니다

v1

의미가 중복되지 않는 concept을 최대한 많이 제안하도록 했습니다. 조합도 이름과 ID를 가진 concept으로 기록했습니다.

v2

따로 재사용할 수 있는 요소를 발견하고, 적은 정의의 조합으로 관찰을 표현하도록 했습니다. 새 조합이라는 이유만으로 concept ID를 추가하지 않습니다.

재사용할 의미가 있는 named composite은 허용했습니다. Primitive 목록이나 concept 수 상한을 정하지 않았고, 이전 정의를 자동으로 병합하거나 삭제하지도 않았습니다.

04 / 근거의 범위
인용한 patch와 전체 labeling은 다릅니다
모든 concept의 존재 여부를 모든 입력에 표시한 실험이 아닙니다. 아래는 기록에 실제 인용된 서로 다른 patch 수입니다. 각 행의 모집단은 1,050개이며, 정의 근거와 표현 근거가 겹칠 수 있습니다.
Dataset · 입력v1 정의 근거v2 정의 근거v2 표현 근거v2 합집합
근거 수와 범위도 달라졌으므로 정의 수 감소만으로 표현력이 유지됐다고 판단할 수 없습니다. 인용 기록은 detection accuracy나 recall이 아닙니다.



05 / 조건과 검증
입력부터 응답까지 대조했습니다
  • 원본 420장·관찰 2,100개의 PNG bytes와 순서가 v1과 같습니다. 두 입력 스케줄의 첨부 횟수 합계는 4,200개입니다.
  • Model·effort·timeout 1,800초·response 제한 2 MiB, backend executable과 실행 인자가 v1과 같습니다.
  • 12개 prompt·schema·응답·순차 catalog, expression 참조와 patch 연결을 검증했습니다.
  • 실험 구현의 전체 CPU 검사 202개와 GitHub CI를 통과했습니다. 이는 구조·참조 검증이며 의미적 grounding 평가가 아닙니다.

해석할 때 남는 한계
Full labeling, semantic GT, detector 생성, held-out 평가는 하지 않았습니다. MNIST 한 번 입력의 A_C001은 관찰 window 자체를 정의 대상으로 삼았습니다. 모든 정의가 원하는 시각적 요소인지도 별도 검토가 필요합니다. 여기서는 검증한 실험 기록을 그대로 보존했습니다.
